## Legend

- ✅ **Verified** — launched and seen running correctly.
- ⚠️ **Limited** — loads and runs but not playable with a standard controller (medal/betting cabinet whose medal I/O is not wired).
- ❌ **Non-functional** — loads but does not reach gameplay (see Notes).
- ▫️ **Untested** — standard input, no special hardware; presumed working.

Special-hardware tags: `315-5881` / `315-5838` (protection/encryption chips),
`RAX` (Acclaim RAX audio board), `RSG` (Radiant Silvergun), `HAMMER` (touchscreen),
`TRACKBALL` (trackball/medal).

## Non-functional

**Fantasy Zone (medal game)** boots and runs code, but its ROM-checksum
self-test fails (`ERROR 10 — ROM HAS CHANGED`) and it never reaches gameplay.
The ROM layout matches MAME (16-bit IC13 EPROM loaded 16LE@0, MPR order/offsets
identical) and the backup RAM persists correctly — clearing it via the test
menu has no effect — so this is an emulation-accuracy difference, not a ROM-map
or backup bug (suspected: unmapped cart region reads `0xFF` where MAME's
`ROM_REGION32_BE`/`ERASE00` reads `0x00`). It is a medal cabinet; the other
untested medal titles (*Dancing Fever Gold*, *Maru-Chan de Goo!*) may behave
similarly.

**Sport Fishing 2** is a **CD-based** ST-V title: the cartridge holds only a
special BIOS (`epr-18343`) while the game data lives on a CD-ROM. This core
emulates the ST-V cartridge slot only — `Load()` forces `cdifs = NULL` for ST-V,
so no CD interface is ever initialised — and the libretro wrapper has no
disc-control / multi-image support. Its DB entry is already flagged "Broken,
needs custom BIOS and CD". (Sea Bass Fishing, by contrast, is a cartridge title
and works.) `MACHINE_NOT_WORKING` in MAME.

## Special hardware

### 315-5881 encryption chip

Astra SuperStars · Final Fight Revenge · Steep Slope Sliders · Tecmo World
Cup '98 · Tecmo World Soccer '98 · Touryuu Densetsu Elan Doree.

### 315-5838 decompression + encryption chip

Decathlete (V1.000 / V1.001) · DaeJeon! SanJeon SuJeon. The 315-5838 combines
Decathlete-specific 16-bit decryption (`decipher()`) with a 12-level Huffman
decompressor. The game uploads tree and dictionary tables at startup via the
chip's register interface. ROM bank selection matches MAME's
`decathlt_prot_srcaddr_w` (SH-2 address bits [24:23] → 8 MB bank window).

### Touchscreen — Critter Crusher / Tatacot

Critter Crusher uses a resistive touchscreen panel wired to the JAMMA I/O
connector. The hardware reports a touched position as a 6-bit X (0–62) and 6-bit
Y (0–46) grid, with a hit-bit in the I/O register. The frontend's pointer device
(`RETRO_DEVICE_POINTER`) is used for input — mouse on desktop, touchscreen on
mobile/Android, or any pointer device. A crosshair overlay can be shown and
coloured via core options (see the Input options in the [README](README.md#core-options)).

### Trackball & medal games

Hashire Patrol Car · Sky Challenger · Nerae! Super Goal · Technical Bowling use
a **trackball** wired to the IOGA I/O gate array (PORT-G); the medal titles also
drive a **medal hopper** (motor on PORT-D, medal-out sensor on PORT-A). The
trackball can be rolled with a mouse / real trackball, an analog stick (either
stick index), or the D-pad — see the input mapping in the [README](README.md#trackball).
Roll speed for the analog/D-pad fallback is set by the
`mednafen_stv_trackball_sensitivity` core option. The medal hopper is fully
emulated: the game PWM-strobes the motor bit, so the core keeps the motor
"energized" for a short hold past each strobe, letting the medal-out sensor line
toggle correctly during payout (fixes the in-game "error 3").

### Acclaim RAX sound board — Batman Forever / Shienryu

Batman Forever uses an external audio expansion board (**Acclaim RAX**) plugged
into the ST-V cartridge slot. The RAX contains an **ADSP-2181 DSP**, four 2 MB
sample ROMs, and a 512 KB program ROM running a custom firmware that handles
sound commands from the SH-2, mixes PCM voices, and streams audio via the SPORT0
serial port.

- Standalone ADSP-2181 CPU emulator adapted from MAME's `adsp2100.cpp` (Aaron Giles, BSD-3-Clause).
- BDMA transfers load firmware segments into DSP program memory; the synthesis engine arms itself via a PM[0x001C] hook patched each BDMA cycle.
- The BDMA IRQ is pulsed (assert + deassert in one step) to mimic MAME's `pulse_input_line`, ensuring a fresh rising edge for every transfer — matching the hardware's edge-triggered latch behaviour.
- Audio is sampled at 44 100 Hz (378 DSP cycles/sample) and mixed into the libretro audio ring buffer via the SPORT0-TX autobuffer mechanism.

## Not in the database

Full ST-V romsets contain cartridges the core does **not** list as supported
titles. These are intentionally absent — they are either not games, or are
marked not-working in MAME itself.

### Standalone titles (present in romsets, no DB entry)

| Set | Game | Why unsupported |
|-----|------|-----------------|
| `chalgolf` | Challenge Golf (Sega, 1999) | Medal game; `MACHINE_NOT_WORKING` in MAME. Has no DB entry, so it loads onto a wrong entry via the shared `ic22.bin` filename and stops at the medal I/O screen (`ERROR NO 4`). |
| `wwshin` | Waku Waku Shinkansen (Sega, 1997) | A mechanical **kiddie ride** (coin-op train), not a playable game — `MACHINE_NOT_WORKING`, "needs inputs", no sound. Does not load (`File unrecognized`). |

### Print Club / Name Club / Purikura

~35 photo-sticker machines (`pclub*`, `pclb*`, `pclove*`, `pcpooh*`, `prc2*`,
`nclub*`, `nameclub`, `pckobe99`, `segabill`, …) are **not supported**. They are
print-club booths that require a camera and a thermal printer — peripherals that
are not emulated (MAME treats them specially too). None are in the database, and
loading one fails with `File unrecognized`.

> A typical full romset (~109 sets) therefore breaks down as: **70 supported
> titles** + 1 BIOS (`stvbios`) + ~35 Print Club machines + 3 not-working
> standalone titles above.
